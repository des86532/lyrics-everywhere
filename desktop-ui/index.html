開始使用

先啟動支援的播放器。YouTube／YouTube Music 需要 Chrome 擴充功能：

  1. 開啟 Chrome 的 chrome://extensions，啟用「開發人員模式」。
  2. 選擇「載入未封裝項目」，指定解壓縮後的 browser-extension 資料夾。
  3. 在 Chrome 的 YouTube 或 YouTube Music 播放影片／歌曲。
來源狀態載入中…

支援範圍：Chrome 中 YouTube／YouTube Music 的公開播放資訊；macOS Spotify。Windows 僅適用於提供公開系統媒體工作階段的播放器。

沒有來源與暫停是不同狀態；未播放、缺少標題／歌手或播放器未提供媒體工作階段時，無法顯示歌詞。

Windows 安裝檔發行前仍須完成互動式桌面實機驗收。macOS DMG 目前未簽署、未公證。

本工具不辨識原始音訊、不提供音訊指紋辨識或翻譯服務。下載項目請以實際發布資訊為準。
