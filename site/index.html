你的電腦執行 Companion

本機讀取，雲端只供下載

桌面程式在這台電腦讀取公開的媒體工作階段並顯示歌詞。查歌詞時會將歌曲標題與歌手送至 LRCLIB 查詢；YouTube 與 YouTube Music 的 Chrome 擴充功能只連到同一台電腦上的 Companion。

Cloudflare Pages 只託管這個下載頁；不執行 Companion、不接收播放資訊，也不提供共用的遠端播放工作階段。

支援範圍與限制

先確認你的播放方式

Windows 10／11 · x64

目標支援系統公開媒體工作階段的桌面播放器，以及 Chrome 中的 YouTube／YouTube Music。Windows 播放器實機驗收完成前不會發布安裝檔。Spotify 桌面版可能提供媒體資訊；不保證每個播放器都會公開工作階段。

macOS · Apple silicon／Intel

保留 macOS Spotify 桌面 connector，並支援 Chrome 中的 YouTube／YouTube Music。

沒有偵測到歌曲？

播放器需提供公開媒體工作階段與標題、歌手資訊。沒有媒體工作階段或缺少必要欄位時，應用程式會顯示無可用播放資訊；不會從原始聲音猜歌。

歌詞可能找不到

同步歌詞依既有歌詞資料來源提供。若查無歌詞，播放資訊仍在本機處理，介面會顯示沒有可用歌詞。
