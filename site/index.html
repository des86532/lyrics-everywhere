Lyrics Everywhere 耳邊字幕 隱私權政策

生效日期：2026 年 10 月 12 日

適用範圍

本政策適用於「Lyrics Everywhere 耳邊字幕」（以下簡稱「本擴充功能」）瀏覽器擴充功能（適用於 Google Chrome 與 Microsoft Edge）。本政策說明本擴充功能在使用者瀏覽支援網站與使用歌詞同步、音訊辨識功能時所處理、儲存與傳輸的資料範圍。

在本機處理的資料

本擴充功能的核心設計為「本機優先」（Local First），絕大多數資料均僅於使用者的瀏覽器環境內運作，不傳送至任何開發者專屬伺服器：

分頁音訊（Tab Audio）

僅在使用者明確點擊「建立字幕」時，透過瀏覽器標準 tabCapture 串流擷取當前 YouTube 分頁的音訊。音訊資料直接在瀏覽器側欄內的本機 WebGPU 背景執行緒（Web Worker）進行 Whisper 語音辨識，完全不被錄製、不保存原始音訊、亦絕不上傳至任何遠端伺服器。

播放中繼資料（Playback Metadata）

在使用者開啟支援分頁時，讀取當前播放之曲目標題、歌手／頻道名稱、影片 ID、播放進度與片長。此資訊僅暫存於擴充功能執行記憶體中，供歌詞查詢與同步比對顯示使用，不會常態保留。

擴充功能本機設定（chrome.storage.local）

儲存使用者的介面偏好（字體大小、讀音顯示）、特定影片的手動校時偏移量（秒數）、手動選取的 LRCLIB 歌曲編號，以及使用者標記不使用自動比對的影片 ID 清單。資料僅存放於使用者本機裝置。

辨識字幕紀錄（IndexedDB）

使用者透過本機模型完成辨識的字幕片段與時間戳記，會儲存在本機瀏覽器的 IndexedDB 資料庫中，以便下次重播同一影片時直接調用。資料完全保存在使用者本機。

傳送到第三方的資料

為提供同步歌詞與本機模型下載功能，本擴充功能僅向下列第三方服務發出必要請求：

LRCLIB（lrclib.net）

為取得同步動態歌詞，本擴充功能會將歌曲標題、歌手名稱、標題關鍵字或影片長度送出至開源公開歌詞資料庫 LRCLIB 進行查詢。LRCLIB 會依其服務政策接收標準 HTTP 請求標頭（包含使用者 IP 位址與 User-Agent）。

Hugging Face（huggingface.co / hf.co）

當使用者在側欄點擊「載入辨識模型」時，擴充功能會自 Hugging Face 下載 ONNX Whisper 語音模型權重檔並暫存在瀏覽器快取中。下載過程為標準 HTTPS 檔案抓取，Hugging Face 會收到使用者的 IP 位址與連線資訊。

我們不做的事

無分析追蹤與無廣告

本擴充功能不包含任何 Google Analytics、Mixpanel 或第三方遙測／追蹤程式碼，亦不含任何廣告 SDK。

不蒐集、不販售個人資料

我們絕不蒐集、不出售、不出租、亦不轉移任何使用者的個人身分資訊、瀏覽歷史或帳戶資料給任何第三方或廣告商。

不上傳任何音訊或語音

所有語音轉文字辨識皆於使用者本機 GPU / CPU 執行，絕不上傳音訊至任何雲端 AI 語音識別 API。

不注入任何未經授權內容

腳本僅在支援之 YouTube 與 Spotify 播放頁讀取必要的播放器資訊與頁面曲目資訊，絕不修改網頁其他內容或讀取個人私密資料。

資料管理與刪除

使用者隨時保有對本機所有儲存資料的完全控制權：

1. 側欄清除： 可隨時在側欄點擊清除校時或快取清除功能。

2. 移除擴充功能： 於瀏覽器擴充功能管理頁面將「Lyrics Everywhere 耳邊字幕」解除安裝，即可立即且永久清除所有儲存在 chrome.storage.local 與 IndexedDB 中的本機資料。
